# Birthday event project

The fork currently contains the original GeoGuess application; the birthday-event behavior described here is **planned, not implemented**.

1. [Requirements and acceptance criteria](event-requirements.md) — **source of truth** for what the event must do.
2. [Fork baseline and gap analysis](current-state-gap-analysis.md) — what existing code already provides and what needs verification or change.
3. [Prioritized implementation roadmap](implementation-roadmap.md) — order of delivery and definition of done.
4. [Implementation backlog](backlog.md) — actionable work items B01–B09 and current status. GitHub Issues are disabled on this fork; migrate when enabled.

Planning maximum: **50 players**, not expected attendance. First round: **event venue**, intended as an easy, slow tutorial. The host must be able to adjust round duration **while the game runs**. Personal imagery after guesses is low priority.
